# Synthetic Banking Risk Analytics & Regulatory Data Quality Platform

## AsterBank

An end-to-end synthetic banking risk analytics and regulatory data
quality platform focused on Basel III Standardised Approach concepts.

## Project Status

Phase 1 — Environment & Repository Setup

## Primary Focus

- Banking data quality
- Data reconciliation
- Basel III Standardised Approach
- Risk-weighted assets (RWA)
- Regulatory data preparation
- Oracle SQL / PL-SQL
- Python ETL
- ML anomaly detection
- Excel/VBA analyst automation

## Regulatory Approach

The primary risk methodology is a simplified educational
implementation of Basel III Standardised Approach concepts.

IRB concepts such as PD, LGD and EAD may be explored as a
secondary analytical/comparison module.

This project does not claim to reproduce an actual bank's
production regulatory methodology.

## Data Disclaimer

All data used in this project will be synthetic, generated,
publicly documented, or educational.

No confidential, proprietary, employer, client, or production
banking data is used.
